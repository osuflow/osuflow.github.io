Search and download osu! beatmaps without leaving the game

osu!flow is a small Windows app for osu! (stable). Press a shortcut and a search card opens over the game. Pick a map, and a moment later it is in song select.

How it works

  1. Press Ctrl Shift D in osu!. The search card opens over the game with results already loaded. You can change the shortcut in Settings.
  2. Search or filter. Type a title, artist or mapper, paste a beatmap link, or use the filters and sliders.
  3. Press Enter on a map. osu!flow downloads it and hands it to osu! the same way double-clicking an .osz file would.

Features

Quick start
The first search runs when osu!flow starts, so the card opens with maps already on screen. Going back to a search you just made is instant.
Filters
Difficulty, genre, language, video, storyboard, featured artists, spotlights and hide installed, as on the osu! website. They apply instantly and are remembered.
Range sliders
Stars, AR, CS, OD, HP, BPM and length each have a two-handle slider, always shown at the bottom of the filters.
Search syntax
stars>5 ar<=9.5 bpm=180..200 keys=4 mapper=name works in the search box. Every condition has to hold on the same difficulty.
Hover, then Enter
Rest the pointer (or a pen, on a tablet) on a map and press Enter to download or Space to preview. Typing a search and pressing Enter never downloads a map by accident.
Downloads
catboy.best is tried first, with osu.direct as the fallback. osu!flow won't launch osu! while a dialog is open.
Windows 11 look
Uses the acrylic backdrop where Windows provides it, and plain dark colours on Windows 10.
Private
No account, no telemetry, no ads. It never touches osu!'s memory or network.

Search syntax

The osu! website's and osu!lazer's conditions work in the search box, and the sliders set the same ones. Combine as many as you like.

TypeFinds
stars>5a difficulty above 5 stars
ar<=9.5 od>8approach rate and overall difficulty (also cs, hp)
bpm=180..200a range
length<3mseconds, m, h or 3:30
keys=4mania maps with that many keys
mapper="some name"or artist=, title=; quote names with spaces
osu.ppy.sh/s/…paste a beatmap link or ID to go straight to that map

FAQ

Does it work with osu!lazer?

No. osu!flow is built for osu! (stable), the classic client.

Is it safe? Why does Windows warn me?

osu!flow is open source, so you can read what it does. It never touches osu!'s memory or network, and it imports maps the way double-clicking an .osz file does. The installer is not code-signed yet, so Windows SmartScreen may say it protects your PC: choose More info, then Run anyway. Every release lists the installer's SHA-256 so you can check your download.

Do I need an osu! account or an API key?

No. Maps come from the public beatmap mirrors catboy.best and osu.direct.

What does it connect to?

The two mirrors above to search and download, and osu!'s own servers (assets.ppy.sh and b.ppy.sh) for cover images and previews. There is no telemetry.

The card doesn't show over my game.

Exclusive fullscreen hides every overlay. In osu!, switch to Borderless or Windowed under Options, Graphics.

What can't it do?

Anything that needs your osu! account: rank achieved, played or unplayed, your favourites, subscribed mappers, recommended difficulty. The mirrors don't know those things.

How do I change the shortcut or remove osu!flow?

Open Settings from the tray icon, click the shortcut box and press the keys you want. To remove it, use Windows' Installed apps.
